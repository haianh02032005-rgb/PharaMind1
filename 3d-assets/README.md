# PharmaMind AI - 3D Assets

Expected exports:

```text
export/cabinet/pharmamind_cabinet.glb
export/compartments/drawer.glb
export/medication/{tablet_round,tablet_oval,capsule,softgel,bottle,medicine_box}.glb
```

Object naming (each compartment must be a separate object):

```text
cabinet_body, screen, drawer_01 ... drawer_09
```

3D models contain only Object / Animation / Interaction ID - all medication
data comes from the backend. Models are for visualization only, never for
identifying real medication.
